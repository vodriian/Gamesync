# Design assets

Game covers are copies of the existing sample assets in `desktop/fixtures/covers/`.
See [desktop source notes](../../../desktop/SOURCE-NOTES.md) for provenance.

Icons come from the app's `desktop/icons/` folder and the installed
`gpui-component-assets` 0.5.1 package. They use the Lucide icon family.
See [Lucide licensing](https://lucide.dev/license).

These assets support an editable reconstruction of the existing app. They do
not contain a personal library, account IDs, API keys, or private notes.
