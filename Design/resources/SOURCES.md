# Design assets

Game covers are copies of the sample assets in `desktop/fixtures/covers/`.
See [desktop source notes](../../desktop/SOURCE-NOTES.md) for provenance.

All UI icons are the supplied SVG files in `icons-new/`, including its `solid/`
variants. Designs import these files directly. The cleanup preserves their
artwork and does not copy or redraw icons. The old Lucide design directory was
removed after migrating its consumers. The deleted half icons remain deleted.

These assets support editable static references. They contain no personal
library, account IDs, API keys, or private notes.
