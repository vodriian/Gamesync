# 2026-09-27

## Omarchy theme mode

- Created `omarchy-desktop` from the clean `codex/desktop-foundation` branch at
  `7bba441`.
- Added an opt-in **Sync with Omarchy theme** checkbox under Look and feel. It
  preserves and restores the saved GameSync appearance when disabled.
- Read Omarchy's active name and `colors.toml` from its XDG state directory.
  GameSync validates required colors, maps them to native tokens, and never
  writes an Omarchy file or installs a hook.
- Watched the stable Omarchy `current` directory so atomic theme replacements
  update open GameSync windows. A periodic check remains active if file watching
  is unavailable. Invalid changes keep the last valid theme.
- Extended Omarchy mode beyond colors: all native and custom surfaces use square
  corners while the mode is enabled, including card shells, covers, thumbnails,
  and selection masks. The sidebar follows Omarchy's primary background instead
  of a separate dark shade. Turning the mode off restores standard GameSync
  colors and radii.
