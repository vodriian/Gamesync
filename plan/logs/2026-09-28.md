## Omarchy mode handoff

- Finished the opt-in Omarchy appearance mode on `omarchy-desktop`.
- The mode reads the active Omarchy name and semantic colors without changing
  Omarchy configuration. It follows atomic theme replacements while GameSync is
  open and keeps the last valid theme if a replacement is incomplete.
- Look and feel contains the persisted **Sync with Omarchy theme** checkbox.
  Bundled appearance choices remain saved and return when the mode is disabled.
- Omarchy mode uses the primary theme background for both the content shell and
  sidebar, matching Omarchy's bar and popup surface convention.
- Omarchy mode applies square corners throughout GameSync, including controls,
  panels, cards, cover images, thumbnails, selection masks, and the GPU card
  compositor. Standard GameSync colors and radii remain unchanged when the mode
  is disabled.
