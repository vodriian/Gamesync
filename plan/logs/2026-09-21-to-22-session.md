# Session log: September 21–22, 2026

## Scope and final direction

Built and refined the native Rust/GPUI GameSync library around physical game
cards. Kept the existing web app as a reference. Eagle and Picked remained
read-only references. Work stayed on `codex/desktop-foundation`.

This log summarizes the final result of the session. Detailed checks and the
intermediate decisions are in [September 21](2026-09-21.md) and
[September 22](2026-09-22.md). Later decisions below supersede the initial
sidebar removal, clipped flip, folder-opening toolbar, and visible shortcut line.

## Library and navigation

- Added Cards, compact Grid, and browsing Table views sharing filters, search,
  selection, virtual rows, and the bounded artwork cache.
- Replaced the inspector with a full-window focused card. Opening and returning
  preserve the browsing state and scroll position.
- Restored the left sidebar after the first card pass: All games, Favorites,
  status counts, collapsible sections, and collection management.
- Added reversible 200 ms sidebar collapse/restore motion with a reduced-motion
  bypass. Kept fixed-width contents inside the animated clip.
- Matched the gap above Status to the gap above Collections.
- Moved Settings to a padded gear button beside the GameSync heading, with a
  tooltip and the existing keyboard shortcut.
- Removed persistent selection decoration from library cards, grid, and table;
  kept hover feedback and internal keyboard selection.
- Removed folder opening from the UI, menu, shortcut, picker, and launcher.
  Normal startup uses app-managed Steam storage. Readable legacy stores remain
  usable in place; incomplete old storage is left untouched.
- Sample mode now has its own persistent store. Sample games support personal
  edits and collection creation without enabling real Steam sync in that store.
- Added Connect Steam to the empty-library screen. It opens General Settings,
  even if another Settings section was previously selected. Filtered empty
  results retain their search guidance.

## Physical cards and native rendering

- Added framed artwork fronts, serif titles, fixed footers, and editable backs.
  Footers now show status and collection badges, an overflow count, and rating,
  replacing branding and favorite text. Removed duplicate artwork status text.
- Replaced the first clipped reveal with whole-card perspective on macOS using
  a repository-local patch of pinned GPUI 0.2.2. Retained upstream attribution
  and license; did not modify the shared Cargo registry.
- Proved the renderer with an actual game card before integrating it: native
  face textures, perspective projection, back-face culling, thin edge, satin
  lighting, and shadows. Added spring tilt, animated front/back turning, smooth
  neutral return, and interruption/reversal from the current motion state.
- Combined cover, gradient, title, and lighting before one rounded artwork mask
  to remove bottom wedges. Kept the footer outside that mask and reserved room
  for shadows and tilt inside virtual rows.
- Reused the live native editor after turns. Preserved drafts, focus, scroll,
  pending-save protection, and cards that leave the active filter after editing.
  Shielded rotating contents and prevented clicks through to the library.
- Reduced motion uses immediate face changes. Animation work stops when settled
  or inactive. Grid and Table remain flat.
- Cached the hovered card and focused faces, with a 64 MiB additional texture
  ceiling that includes retired in-flight allocations. Pose changes reuse face
  pixels; content changes invalidate them. No per-pointer CPU readback/upload.
- Softened card and focused-view shadows, especially in light mode. Removed
  all-caps presentation labels. Deferred the optional cover-colored backdrop.

## Toolbar and focused viewer

- Combined library controls into an overlaid toolbar. On macOS, the compositor
  blurs content beneath it; oversized captures and Linux use a simpler fallback.
- Replaced Cards/Grid/Table labels with icons and tooltips. Rounded the search
  field, added a search icon, and matched the outer 38 px control height.
- Removed the large bottom help bar and bottom content inset. Kept a compact
  corner control for help/sync information so cards can scroll to the edge.
- Removed the description override checkbox and input. Existing personal
  descriptions remain readable and are preserved by unrelated saves.
- Adapted Eagle's viewer thumbnail strip: horizontal virtualization, shared
  image cache, 80 px cells, active thumbnail frame, and native scrolling.
  Thumbnail navigation uses the existing pending-save guard.
- Moved the strip to the bottom, removed the shortcut text line, and added a
  show/hide control before Previous/Next, plus the T shortcut. The reversible
  200 ms transition respects reduced motion and keeps card texture size fixed.

## Settings

- Left-aligned General, Look and feel, and AI navigation, with icons.
- Removed Disconnect, the sample-library explanation, and session-only keys.
  Steam uses secure OS credential storage. Remove key is right-aligned and only
  appears when a saved key exists; removing it preserves games and personal data.
- Added UI-only connection previews for Ollama, OpenAI, Claude, Grok, and Gemini.
  Model entry precedes API key entry. Dummy-key test/add/remove states are
  interactive and explicitly simulated. AI forms make no network requests and
  do not persist credentials or configuration.

## App packaging and Git

- Added the supplied app icon to the macOS development and release bundles.
- Committed the accumulated native app work as `e9d53b4`.
- Added a repeatable macOS packaging script and committed it as `076329a`.
  It builds the locked optimized profile, copies the executable and icon into a
  standalone app, reads the linked minimum OS, verifies an ad-hoc signature,
  and creates a ZIP.
- Produced GameSync 0.1.0 for Apple Silicon: approximately 27 MiB for the app and
  12 MiB for the ZIP, under `desktop/target/macos/`. Rebuilt both after adding
  Connect Steam. These generated artifacts remain outside Git.
- The follow-up commit containing this log includes the Connect Steam fix.
  No commits were pushed during this session.

## Validation and remaining limits

- During the renderer pass: 71 offline tests passed; four optional network or
  OS-credential tests remained ignored. Application and patched GPUI Clippy,
  formatting, and macOS builds passed. Upstream GPUI unit tests were not run.
- Native checks covered views, sidebar, filters, search, focus/return, light/dark
  themes, bright/portrait/landscape/missing covers, long titles, and the minimum
  window size. Checked tilt, edge-on pose, turns, reversal, keyboard input,
  reduced motion, editor selection/dropdowns, and background-click protection.
- Disposable-library rating/status/note edits survived restart, including a
  status change outside the active filter. A focused storage test verified
  separate sample storage and preservation of edits across reopening.
- The 10,000-record missing-cover smoke check covered scrolling, opening,
  turning, return position, and Table. Recorded additional texture peaks were
  14.80 MiB for stress and 12.80 MiB for the actual-artwork motion sample. These
  short debug runs are not release benchmarks or unique-artwork stress tests.
- Later UI refinements used focused native checks and builds instead of repeated
  broad suites, as requested. Checked the mock key flow with dummy values.
- Release compilation, strict signature verification, and normal native launch
  passed. The release showed My games and the Steam prompt; Connect Steam opened
  the profile/key form. Dynamic dependencies are system libraries.
- No real Steam account sync or real credential mutation was performed in this
  session's UI checks. AI integration remains a mock. Table sorting, column
  controls, and bulk editing remain pending.
- Linux compilation/runtime and Linux 3D remain unverified/pending. Other display
  scales, texture-budget exhaustion, and broad post-polish regression remain
  unverified. Custom GPUI controls retain limited accessibility-tree exposure.
- The binary declares macOS 11.0 minimum, but older macOS runtime compatibility
  was not tested. Intel/universal builds, Developer ID signing, and notarization
  remain pending. The current package is for local testing.
