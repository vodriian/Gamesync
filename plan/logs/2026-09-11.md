### Design review

| Before | After | Why |
| --- | --- | --- |
| Eagle's square asset tiles and file metadata | Portrait covers, game captions, and game details | Fit the library task while retaining the proven layout |
| Fixed-width search beside both panes | Search can shrink within the toolbar | Keep controls usable when the center pane narrows |
| Window close leaves a demo process without a window | Quit when the last window closes | Make development relaunch predictable |
| Arrow selection recenters visible rows | Reveal only rows outside the viewport | Keep navigation steady |
